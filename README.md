# Star 🌟 — 一个用 Python 写的 AI 心理咨询对话机器人

> 一个基于规则匹配的对话代理，模拟罗杰斯式 / 心理动力学取向的心理咨询师，带有轻量级长期记忆系统和危机干预意识。

Star 是一个纯 Python 编写的**心理咨询对话机器人**。它不依赖任何大模型、外部 API 或第三方库，完全依靠正则规则 + 记忆管理，模拟一位倾听型的心理咨询师。

## ✨ 功能特性

- 🧠 **长期记忆** — 记住用户提到的主题（母亲、父亲、自我状态、需求等），并在合适时机主动引用。
- 💬 **罗杰斯式回应** — 以共情、澄清、赋能为核心，避免直接给建议。
- 🎭 **多维度规则** — 覆盖 CBT、心理动力学、人本主义、危机干预等咨询取向。
- 🛡️ **危机识别** — 能识别自伤 / 自杀相关表达，并引导至危机热线。
- 🔁 **冷却机制** — 防止记忆引用过于频繁，让对话更自然。
- 💾 **持久化存储** — 支持将记忆保存为 JSON 文件，并在下次启动时重新加载。
- 📦 **零依赖** — 仅使用 Python 标准库，`python star.py` 即可运行。
